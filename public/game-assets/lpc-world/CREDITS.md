# Willowmere & The Lantern Vault — scenery credits

These sample environments use **LPC Revised**, curated by **Eliza Wyatt (DeathsDarling)**, pinned to [commit f07f7f5892e67c932c68f70bb04472f2c64e46bc](https://github.com/ElizaWy/LPC/tree/f07f7f5892e67c932c68f70bb04472f2c64e46bc).

Artwork by **Lanea Zimmerman (Sharm)** and **Eliza Wyatt (DeathsDarling)**. The flower sheet also includes work by **Hyptosis** and **BlueCarrot16**. Rocks and shelves are original work by Eliza Wyatt. The Dungeon Elements source credits Lanea Zimmerman for the original artwork and Eliza Wyatt for recoloring.

All selected files are provided under **OpenGameArt Attribution 3.0 (OGA-BY 3.0)**. The [complete license](./OGA-BY-3.0.txt), [per-file manifest with source links and SHA-256 hashes](./manifest.json), and original creator credit notices are included alongside the artwork. Attribution is required when redistributing the artwork. There is no share-alike requirement for these selected files.

The files remain unmodified originals. Dmap selects source rectangles at runtime and authors its own map layouts, collision footprints, and dialogue. The three assembled houses retain their component credits for masonry, doors, windows, steps, chimneys, and roofing. These components are listed in the manifest and their original notice files accompany this directory.

Primary upstream sources include [LPC base assets](https://opengameart.org/content/liberated-pixel-cup-lpc-base-assets-sprites-map-tiles), [LPC interior castle tiles](https://opengameart.org/content/lpc-interior-castle-tiles), [LPC dungeon elements](https://opengameart.org/content/lpc-dungeon-elements), [LPC animated doors](https://opengameart.org/content/lpc-animated-doors), and [LPC modified base tiles](https://opengameart.org/content/lpc-modified-base-tiles). The LPC base-assets page explicitly permits Lanea Zimmerman's and Stephen Challener's work under OGA-BY 3.0 in its attribution instructions. The terrain notices also record Hyptosis's permission to use his CC-BY 3 artwork under OGA-BY 3.0.

To reproduce the import from the pinned sources and validate every PNG hash, run `pnpm exec tsx scripts/download-lpc-world.mjs --download` from the repository root. Running the script without the flag refreshes local hashes and source-frame metadata without network requests.
