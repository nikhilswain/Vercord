# Background music

User-supplied tracks from the local root `sounds/` folder:

| Browser file           | Original             |
| ---------------------- | -------------------- |
| `peaceful-village.mp3` | `peaceful ville.ogg` |
| `sunset-plains.mp3`    | `sunset_plains.wav`  |

160 kbps, 44.1 kHz MP3 copies made with `scripts/prepare-game-music.py`.
Originals remain local and are not included in the build.

Track names, URLs and the default are configured in
`src/features/audio/music-catalog.ts`.
